`kanji-betsu.json` is the unmodified stroke data for 別 from
[mnako/hanzi-writer-data-ja](https://github.com/mnako/hanzi-writer-data-ja/blob/master/data/%E5%88%A5.json),
retrieved on September 29, 2026. This is the seven-stroke character in the
[reported mobile playback issue](https://kakehashiapp.com/community/7a8432c5-c09c-4dfc-a7af-cbecedfa34fb).
