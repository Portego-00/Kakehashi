## Web moderation implementation

Issue detail now exposes a Close issue / Reopen issue action to the server-verified WaniKani username `Portego`, including other authors’ threads. Existing author/configured-admin controls remain. Status moderation is a separate permission from deletion; the new Portego privilege does not grant deletion of other authors’ threads. Read-only deployments and unverified sessions cannot mutate status.
